# АСКУЭ ИНТЭП (Клиентское рабочее место)

Клиентское программное обеспечение автоматизированной системы коммерческого учета электроэнергии (АСКУЭ).

## Среда разработки и требования

* **IDE:** Borland C++ Builder 6 (Update Pack 4 / Build 10.166)
* **ОС сборки:** Windows XP / Windows 7 x86 (на 64-битных ОС требуется запуск в режиме совместимости)/ Windows 10 x86
* **База данных:** Oracle Database 10g / 11g / 12c (требуется Oracle Instant Client x86)

---

## Необходимые компоненты и библиотеки

Для открытия форм в дизайнере и сборки проекта требуются следующие сторонние библиотеки:

1. **EhLib (версия 3.x / 4.x)** — компоненты `TDBGridEh`, `TPrintDBGridEh`.
2. **ODAC (Oracle Data Access Components)** — компоненты прямого доступа `TOraSession`, `TOraQuery`.
... итд
 Все необходимые пакеты и инсталляторы библиотек можно скачать в разделе **[Releases](../../releases/tag/v3.5.5.50-deps)**.

---

## Порядок настройки среды перед первой сборкой

1. Установите Borland C++ Builder 6.
2. Установите пакеты компонентов из раздела Releases:
   * Откройте в IDE `.bpk`/`.bpr` пакета $\rightarrow$ нажмите **Compile** $\rightarrow$ нажмите **Install**.
3. Проверьте пути поиска в IDE (**Tools -> Environment Options -> Library**):
   * Добавьте путь к папке скомпилированных `.dcu` и `.hpp` сторонних компонентов.
4. Откройте группу проектов: `Askue.bpg` (или `Askuer.bpr`).
5. Выполните **Project -> Build All Projects**.
